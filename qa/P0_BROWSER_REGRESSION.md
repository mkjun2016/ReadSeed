## 발견·수정

1. 종래에는 선택된 본문 전체에 52px 줄간격이 적용돼, 주석이 없는 문단도 크게 벌어졌다.
2. 주석이 실제로 있는 텍스트 블록에만 임시 클래스를 적용하도록 변경했다.
3. 추가 줄간격을 34px에서 22px로 조정해 18px 본문 기준 52px에서 40px로 줄였다.
4. 임시 class를 제거한 뒤 `class=""`가 남는 문제를 수정해, 기존 class 속성을 정확히 복원한다.
