# Frontend

Manifest V3 기반 Chrome Extension이다. Popup의 **분석하고 표시하기** 버튼이 활성 탭의 본문 또는 선택 영역을 추출하고, 로컬 FastAPI를 거쳐 받은 발음·쉬운 뜻과 핵심 정보를 별도 Overlay로 표시한다.

## 파일별 역할

| 파일 | 역할 |
|---|---|
| `manifest.json` | Popup, 콘텐츠 스크립트, 로컬 API 호스트 권한 정의 |
| `content.js` | 전체·선택 영역 추출, 발음·쉬운 뜻·핵심 정보 Overlay, 동시 읽기 |
| `overlay.css` | 클릭을 가로막지 않는 주석·하이라이트·읽기 보조 레이어 |
| `popup/popup.html` | 기능별 토글, 주석 크기·밀도·읽기 속도, 실사용 평가 UI |
| `popup/popup.js` | 서버 확인, 문장 분석, 설정 저장, 평가 기록·JSON 내보내기 |

## 동작 흐름

```
분석하고 표시하기 → 전체 또는 선택 영역 추출 → 문장 분리(최대 20개)
→ POST http://127.0.0.1:8000/annotate
→ 발음·쉬운 뜻·핵심 정보 Overlay 표시 → 필요시 동시 읽기 시작
```

원문 텍스트 노드를 수정하거나 `span`으로 감싸지 않는다. 분석 중에는 선택된 본문 루트에만 임시 클래스를 붙여 줄간격을 확보하고, Overlay를 지우거나 재분석하면 클래스를 제거한다.

## 설치·테스트

1. 로컬 API를 실행한다. 자세한 명령은 상위 [README.md](../README.md)를 참고한다.
2. Chrome `chrome://extensions`에서 개발자 모드를 켠다.
3. **압축해제된 확장 프로그램 로드**로 이 `frontend/` 폴더를 선택한다.
4. 일반 웹페이지에서 ReadSeed 아이콘 → **분석하고 표시하기**를 누른다.

코드 수정 뒤에는 확장 프로그램의 새로고침 버튼과 대상 웹페이지 새로고침이 필요하다.
